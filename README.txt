FlooWay is a Harry Potter–inspired travel booking web application that allows users to explore magical destinations, browse curated travel packages, plan trips, manage bookings, and save packages to a personal wishlist through an interactive and immersive interface.

The platform features a dynamic destinations map, house-themed travel packages, trip planning and booking systems, wishlist functionality, and a fully functional authentication workflow. Users can register, log in, save trips, view bookings, and manage their wishlist through a personalized dashboard. Packages can be searched, filtered by house, price, and duration, and sorted by price, duration, and popularity.

The site is designed with a consistent wizarding aesthetic using parchment-style layouts, cinematic backgrounds, and animated UI components to create an engaging themed experience.

Tech Stack: HTML, CSS, JavaScript, LocalStorage
